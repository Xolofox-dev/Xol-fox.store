    Pertanyaan Umum (FAQ)

    Bagaimana cara melakukan pemesanan?+
    Pilih produk di halaman Katalog, klik "Beli", lalu transaksi Anda akan otomatis muncul di halaman Transaksi dengan status "Diproses".
    Berapa lama waktu pengiriman?+
    Untuk area Jabodetabek 1-2 hari kerja, luar Jabodetabek 2-5 hari kerja, dan area terpencil 5-7 hari kerja.
    Apakah bisa melakukan pembatalan pesanan?+
    Ya, Anda dapat membatalkan pesanan di halaman Transaksi selama status pesanan masih "Diproses".
    Apakah data profil saya aman?+
    Ya, semua data profil Anda tersimpan secara lokal di browser Anda sendiri (localStorage). Tidak ada data yang dikirim ke server mana pun.
